# Admin console fonts

Self-hosted so the admin pages make no third-party requests (UI-UX.md §4.2, §13).
Latin subset, variable weight, from the `@fontsource-variable/*` 5.3.0 packages on npm
(downloaded October 26, 2026). Each font is licensed under the SIL Open Font License 1.1;
the license text sits next to it.

| File | Font | Used for | License |
|---|---|---|---|
| `plus-jakarta-sans-latin-variable.woff2` | Plus Jakarta Sans | Headings, display, labels in illustrations | `plus-jakarta-sans-OFL.txt` |
| `inter-latin-variable.woff2` | Inter | Body text, labels, buttons | `inter-OFL.txt` |
| `jetbrains-mono-latin-variable.woff2` | JetBrains Mono | IDs, codes, the code field | `jetbrains-mono-OFL.txt` |
